贪吃蛇小游戏规划说明

一个无需构建、可在现代浏览器直接运行的纯前端小游戏。目标是优先完成清晰、可控、可验收的核心玩法，再根据真实使用反馈扩展内容。

交付形态单页 Web 应用
推荐技术Vue 3 + Canvas 2D
部署目标GitHub Pages
规划目录
1. 目标与范围2. 玩法规则3. 界面与交互4. 数据与流程5. 技术实现6. 验收标准7. 实施顺序

1. 目标与范围

让玩家打开页面后 5 秒内理解玩法，并通过键盘完成一局完整的贪吃蛇游戏。基础版强调规则稳定和代码可维护，不以内容数量取胜。

P0 必须有

核心能力

  • 开始、暂停、继续和重新开始。
  • 方向键和 WASD 控制移动方向。
  • 吃到食物后增长蛇身并增加分数。
  • 撞墙或撞到自身时结束游戏。
  • 实时显示分数、最高分和游戏状态。
非目标

本期不做

  • 账号、排行榜和云端存档。
  • 多人对战、障碍物和特殊道具。
  • 关卡系统、皮肤商城和音效管理。
  • 移动端虚拟摇杆和复杂动画。

2. 玩法规则

20 × 20逻辑网格，每格固定一个坐标单位
150 ms初始移动间隔，后续可随分数加速
10 分每吃到一个食物获得的基础分
  1. 游戏开始时，蛇身包含 3 个连续格子，位于场地中央并向右移动。
  2. 食物随机生成在空闲格子上，不能与蛇身或已有食物重叠。
  3. 每个时间步只接受一次有效转向；禁止 180 度反向移动。
  4. 蛇头进入食物格时，蛇身不删除尾节点，分数增加 10。
  5. 蛇头越界或进入身体格时，状态切换为「游戏结束」。
  6. 最高分保存在浏览器本地；清空站点数据后允许丢失。

3. 界面与交互

页面结构

  • 顶部状态栏：当前分数、最高分和操作按钮。
  • 中央游戏区：固定比例画布，绘制网格、蛇和食物。
  • 底部提示：展示键盘操作说明和当前状态。
  • 状态遮罩：覆盖准备开始、已暂停和游戏结束状态。

交互反馈

  • 页面加载后不自动移动，玩家点击「开始游戏」后进入运行状态。
  • 空格键切换暂停和继续；游戏中按方向键不会滚动页面。
  • 结束遮罩显示本局分数，并提供「再来一局」按钮。
  • 按钮具备键盘焦点样式，文本与背景保持可读对比度。

4. 数据模型与游戏流程

statusready | playing | paused | over驱动按钮、遮罩和游戏循环是否运行。
score / bestScorenumber本局分数与本地保存的最高分。
1. 等待等待计时器到达下一时间步。
2. 转向应用合法方向，忽略反向输入。
3. 碰撞判断蛇头是否越界或撞身。
4. 移动添加新蛇头并按需移除蛇尾。
5. 结算更新分数、食物和结束状态。

5. 技术实现

页面与渲染

  • 使用单个 snake.html 承载模板、样式和逻辑，降低部署成本。
  • Vue 3 全局构建负责状态、按钮和遮罩；Canvas 2D 负责游戏画面。
  • 逻辑坐标与渲染像素分离，画布缩放时保持 1:1 正方形比例。
  • 绘制函数只读取状态，不在绘制过程中修改游戏状态。

循环与质量

  • 使用单个定时循环推进逻辑，并在暂停或结束时停止。
  • 将方向判断、碰撞检测和食物生成拆为纯函数，便于单独验证。
  • 监听键盘后清理已有定时器，避免重复开始导致多循环并行。
  • 不引入构建工具、后端服务或第三方游戏引擎。

建议文件snake.html 为唯一运行入口；本规划文件 snake-game-plan.html 仅用于说明，不参与游戏逻辑。

6. 验收标准

  • 页面可在本地直接打开，也可通过 GitHub Pages 访问，无控制台错误。
  • 点击开始后蛇按固定节奏移动，方向键与 WASD 均能正确改变方向。
  • 连续快速按键或输入反向时，游戏不会穿模、反向或出现多循环。
  • 吃到食物后分数增加 10，蛇身长度增加 1，食物重新出现在空闲格。
  • 撞墙或撞到自身后立即结束，分数冻结且可重新开始。
  • 暂停后状态与画面不再推进，继续后从原状态恢复。
  • 刷新页面后最高分仍可读取；无历史记录时显示为 0。
  • 在 360 px 宽度以上的视口中，游戏区和操作按钮无横向溢出。

7. 实施顺序

  1. 骨架：完成页面布局、Canvas 绘制和准备状态遮罩。
  2. 核心循环：完成移动、计时、方向输入和暂停。
  3. 规则闭环：完成食物、增长、碰撞、计分和本地最高分。
  4. 体验打磨：完成响应式布局、键盘无障碍和视觉反馈。
  5. 验证部署：覆盖验收用例，并发布到 GitHub Pages。
